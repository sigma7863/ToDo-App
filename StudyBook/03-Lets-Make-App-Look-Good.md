アプリの見た目を整えよう
前回の学習では、入力フォームに TODO を入力して、「追加」ボタンをクリックしたら一覧で表示できるようにしました。今回は入力フォームや TODO 一覧の見た目を整えて、より使いやすいアプリにしていきます。

【実習】トップバーを表示してみよう
まず最初に、タイトルの見た目を整えましょう。今はタイトルの「My TODO」が画面の左上にくっついてしまっているので、少し不恰好ですね。アプリでよくあるトップバーを表示して、その中にタイトルを入れてみましょう。

トップバーなどのアプリの基本的な部品を表示するときは、Scaffold という Composable を使うのが便利です。Scaffold は画面全体のレイアウトを組むための Composable で、トップバーやボトムバー、スナックバーなどを表示する領域を用意してくれています。Scaffold を使うことで、トップバーなどを簡単にバランスよく表示できます。

また、トップバーは TopAppBar という Composable が用意されているので、そちらを使いましょう。Column に使われている padding(paddingValue) は、用意された TopAppBar のスペース確保のために必要とされています。既存のタイトルの Text() は削除して、Scaffold と TopAppBar を使って MyTodoApp() を以下のように実装してみましょう。

fun MyTodoApp() {
    val todo = remember { mutableStateOf("") }
    val todoList = remember { mutableStateListOf<String>() }

    Scaffold(
        topBar = {
            TopAppBar(
                title = { Text(text = "My TODO") }
            )
        }
    ) { paddingValue ->
        Column(modifier = Modifier.padding(paddingValue)) {
            TextField(
                ...
        }
    }
}

実装できたらプレビュー画面、または実際にアプリをビルドして見た目を確認してみましょう。アプリにトップバーが表示されていれば OK です。

トップバーが表示できた

実装したコードについて簡単に解説します。先ほどもお伝えした通り、Scaffold は画面全体のレイアウトを組むための Composable なので、画面全体を囲むように実装しました。そして Scaffold の引数の topBar には、トップバーを表示するための Composable である TopAppBar を渡しています。

TopAppBar では title に Text(text = "My TODO") を渡しました。こうすることでタイトルに「My TODO」が表示されるようになりました。title に純粋な文字列ではなく、Text という Composable を渡しているのがポイントです。もしタイトルの文字色を変えたくなったり、書体を変えたくなった場合は、渡している Text を修正すれば良いためです。

例：タイトルを変えてみる

例えば、上記の画像のように実装すれば、タイトルの色と書体を変えることができます。Composable を受け渡すことによって、自由な見た目の作成ができるようになっているのです。ちなみに、トップバーの背景色を変えたい場合は、TopAppBar に colors という引数が用意されているので、そちらに TopAppBarDefaults.smallTopAppBarColors([好きな色]) を指定して修正してください。

例：トップバーの背景色を変えてみる

トップバーの背景色や文字の色は皆さんの好みに合わせて実装してみてくださいね。なお、このテキストではデフォルト設定の色のままで進めていきます。

【実習】フォームのレイアウトを整えよう
トップバーが表示できたら、次にフォームのレイアウトを整えていきましょう。まず気になるのは、フォームの左端が画面の端にくっついてしまっていることですね。余白を設定してレイアウトを整えましょう。

ただ、各部品ごとに余白を設定していくのは手間がかかりますし、設定ミスによってズレが生じる可能性もあります。そのため、今回はフォームだけに余白をつけるのではなく、画面全体の余白を設定しましょう。以下のように画面全体を囲っている Column に対して余白をつけて、フォームに設定している上部の余白を削除しましょう。

 ) {
    TextField(

        onValueChange = { text -> todo.value = text },
        modifier = Modifier.padding(bottom = 16.dp)
    )

      ...

余白の設定ができたらプレビューまたはアプリをビルドして確認してみましょう。フォームの左端と上部に同じ余白が設定されてれば OK です。

フォームに余白を設定した

次はフォームの「追加」ボタンをフォームの右に移動しましょう。ユーザの視点で考えると、フォームに入力すると視線が左から右に移動していくので、フォームの右にボタンがあると視線の流れから自然とボタンへ辿り着けるためです。LINE や Twitter アプリなど、文言を入力して送信するときのボタンは右端にあることが多いですよね。

「追加」ボタンをフォームの右に置くためには、横並べするときに便利な Row という Composable を使います。入力フォームと「追加」ボタンを Row の中に入れてください。

Column(
    modifier = Modifier
       .padding(paddingValue)
       .padding(16.dp)
) {
    Row(verticalAlignment = Alignment.CenterVertically) {
        TextField(
            value = todo.value,
            onValueChange = { text -> todo.value = text },
            modifier = Modifier.padding(end = 16.dp)
        )
        Button(onClick = {
            todoList.add(todo.value)
            todo.value = ""
        }) {
            Text(text = "追加")
        }
    }
    todoList.forEach { item ->
        Text(text = item)
    }
}

実装できたらプレビューまたはアプリをビルドして確認してみましょう。「追加」ボタンがフォームの右側に配置されていたら OK です。

「追加」ボタンをフォームの右に移動した

このように、Row の中に置いた Composable は自動的に左から並んでいきます。Row の引数に渡した verticalAlignment = Alignment.CenterVertically というのは、Row の中の要素を上下中央揃えにする設定です。

Alignment.CenterVertically のかわりに Alignment.Top を設定すれば各要素が上揃えになりますし、Alignment.Bottom を設定すれば下揃えになります。今回は見た目を整えるため、上下中央揃えにしました。

ボタンがつぶれて「追加」の文字が縦になっているのが気になるかもしれませんが、こちらはあとで修正しますので、今はこのままにしておいてください。

また、フォームとボタンの間に余白を空けるために Modifier.padding(end = 16.dp) を設定しました。ここで、右に余白をつけるのに right ではなく end を指定したことに疑問を感じたでしょうか。この Android における左右の設定方法には理由があるので、詳しく見ていきましょう。

【講義】左右の設定について
Android では方向を指定するとき、上は top で下が bottom とわかりやすいのですが、左は start で右に end を使います。これは Android 端末が多言語に対応しているためです。

私たちに馴染み深い日本語や英語では、文字を左から右に読んでいくため、左から右に視線を動かしたときに使いやすいように UI が設計されます。しかし、世界にはアラビア語のように右から左に読んでいく言語もあります。そのような言語では右から左に視線を動かしたときに使いやすいように、UI の配置も左右反転するのが望ましいです。

Android 端末ではどちらの言語を使う人もアプリを使いやすくするため、言語によって UI を反転する機能があります。この機能を使えば、1 つのアプリでどちらの言語の人にも対応できるということです。実際に反転機能を確認したいので、試しにエミュレータの言語設定を変更してみましょう。

エミュレータの「設定」→「システム」→「言語と入力」→「言語」と画面を開いて、「言語を追加」をクリックしてください。そうしたら言語一覧から下のほうまでスクロールして「العربية」（アラビア語）を選択しましょう。その後に地域を選択する画面が表示されるので、いずれかの地域を選択してください。選択できたら、アラビア語を一番上に移動させて、端末の標準言語にしてください。

端末の言語をアラビア語に変更した

端末の言語をアラビア語に変更できたら、TODO アプリを開いてみましょう。レイアウトが左右反転しているのが確認できたでしょうか。

アラビア語で表示する TODO アプリ

アプリでは左右反転していてもフォームと「追加」ボタンの間に余白が設定されています。これは、フォームに対して Modifier.padding(end = 16.dp) を設定したためです。つまり、日本語や英語のような左から右に読む言語においては、start は左側、end は右側の指定になります。一方で、アラビア語のような右から左に読む言語においては、start は右側、end は左側の指定になるのです。

これが、Android で左右の指定を start と end で行う理由になります。皆さんが開発するアプリはアラビア語圏の人々を想定していないかもしれませんが、こういった理由があるというのは理解しておくと良いでしょう。

レイアウトが反転していることが確認できたら、開発に戻りますのでエミュレータの言語を日本語に戻しておいてください。アラビア語が不要であれば、言語設定の右上のメニューから削除できます。

アラビア語を端末から削除する

左右の設定方法について理解できたところで、フォームの実装に戻りましょう。

【実習】フォームに入力したときの見た目を整えよう
日本語に戻してアプリを表示できたら、試しにフォームで文言を入力してみましょう。文字数を増やしていったときに「追加」ボタンが見切れてしまう問題があるはずです。

フォームに入力していたら「追加」ボタンが見切れてしまう問題

このような不具合があると、長い内容を TODO に追加できません。アプリを開発するときには簡単な動作だけではなく、このように長い文字が入ったときにどうなるか、ということも確認しておくことが大切です。それでは修正していきましょう。入力フォームを以下のように修正します。

TextField(
    value = todo.value,
    onValueChange = { text -> todo.value = text },
    modifier = Modifier
        .padding(end = 16.dp)
        .weight(1f)
)

修正できたら、アプリをビルドしてフォームに文言を入力してみましょう。文字数が増えたときに、「追加」ボタンが見切れるのではなく、フォームが下に改行されていくようになりました。また、ボタンの「追加」の文字も正常に表示されるようになりました。

フォームが適切な位置で改行される

ここで追加した weight() という処理は Row() の中に使用できるもので、Row() の中に配置された要素の横幅比を設定するものです。ここでは入力フォームだけに weight() を設定したので、入力フォームの横幅は「追加」ボタンを除いた横幅いっぱいに広がります。逆に言えば、入力フォームは「追加」ボタンを除いた横幅以上には広がらなくなるので、「追加」ボタンを押し出さなくなります。

ちなみに「追加」ボタンに Modifier.weight(0.5f) を指定すると、以下のようにフォームと「追加」ボタンの横幅比が 2 : 1（1f : 0.5f）になります。

フォームと「追加」ボタンの横幅比が 2 : 1 になった

このように横幅が変化する UI に対しては weight で横幅比を設定したり、各要素の横幅をあらかじめ決めておくと見た目が崩れにくくなります。「追加」ボタンに Modifier.weight(0.5f) をつけた場合は、もとに戻してから次に進んでください。

【実習】TODO 一覧の見た目を整えよう
フォームの見た目が整えられたら、次に TODO 一覧の見た目を整えていきましょう。フォームにいくつか文言を入力して「追加」ボタンを押すと TODO 一覧が表示されますが、今のままだと見づらいですね。

TODO 一覧に余白がなくて見づらい

TODO 一覧の見た目を整えるために、個別の TODO を表示する Composable を作成しましょう。MyTodoApp() とは別の Composable として以下のように実装します。

 @Composable
 fun TodoItem(text: String) {
     Text(text = text, modifier = Modifier.padding(vertical = 4.dp))
 }

作成できたらフォームと TODO 一覧の間に余白をつけ、 MyTodoApp() の TODO 一覧の部分を TodoItem() に書き換えましょう。

 Row(
    verticalAlignment = Alignment.CenterVertically,
    modifier = Modifier.padding(bottom = 16.dp)
 ) {
    TextField(
        value = todo.value,
        onValueChange = { text -> todo.value = text },
        ...
}
todoList.forEach { item ->
    TodoItem(text = item)
}

実装できたらビルドして TODO をいくつか入力してみましょう。余白が追加されて TODO 一覧が見やすくなっています。

TODO 一覧が見やすくなった

今回の修正で TodoItem() を別の Composable として作成したのは、この後の講義で各 TODO に編集ボタンや完了ボタン、削除ボタンを追加するためです。MyTodoApp() の中に書くと、1 つの Composable が肥大化してコードが見づらくなってしまうので、適度に Composable を分離していくことは大事です。

アプリの見た目が整えられたので、次の講義では TODO を完了できるようにしていきましょう。
